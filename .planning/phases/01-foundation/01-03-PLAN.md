**TextStoreBuilder** (mutable build phase):
Uses the two-phase pattern from research:

Structure:
- strings: Vec<&'static str> -- indexed by StringId.0, arena-backed slices
- dedup: HashMap<&'static str, StringId> -- hashbrown for no_std compat
- arena: Bump -- declared LAST so it's dropped last (critical for safety)

Drop order: Rust drops fields in declaration order. Vec<&str> and HashMap<&str, StringId> drop by freeing their heap buffers -- they do NOT dereference the &str pointers during drop. So arena being dropped last is safe. But declare arena last for clarity.

Methods:
- new() -> Self
- intern(&mut self, s: &str) -> StringId:
  1. Check dedup HashMap first -- return existing ID if found
  2. Allocate in arena: self.arena.alloc_str(s)
  3. SAFETY: transmute &'bump str to &'static str (arena outlives all refs, sound because bumpalo allocations are pointer-stable and arena is moved into TextStore on build)
  4. Push to strings Vec, insert into dedup, return new StringId
- resolve(&self, id: StringId) -> Result<&str, StoreError>: Vec index lookup
- len(), is_empty()

**TextStore** (immutable read phase):
On build(), copy all string data into a contiguous Vec<u8> buffer. This eliminates arena references in the final type, making it trivially safe and Miri-clean.

Structure:
- buffer: Vec<u8> -- contiguous string bytes
- offsets: Vec<(u32, u32)> -- (offset, len) indexed by StringId

Methods:
- build(self) -> Arc<TextStore>: iterate strings, copy bytes to buffer, record offsets
- resolve(&self, id: StringId) -> Result<&str, StoreError>: index into offsets, slice buffer, from_utf8 (safe: all input was valid &str)
- len(), is_empty()

Add `pub mod text_store;` and `pub use text_store::{StringId, TextStore, TextStoreBuilder};` to lib.rs.

For no_std compatibility:
- Use alloc::sync::Arc when not(feature = "std")
- Use alloc::vec::Vec when not(feature = "std")
