Create crates/core/src/span.rs implementing Span (FOUN-02):

Span struct:
- Fields: start: u32, end: u32 (private, half-open range [start, end))
- Derives: Clone, Copy, Debug, PartialEq, Eq, Hash
- cfg_attr serde derive when feature = "serde"

Methods:
- new(start, end) -> Self: panics if start > end
- start(), end(), len(), is_empty(): accessors
- contains(&self, other: &Span) -> bool: full containment check
- overlaps(&self, other: &Span) -> bool: non-zero intersection (adjacent spans do NOT overlap)
- merge(&self, other: &Span) -> Span: smallest span covering both
- split_at(&self, offset: u32) -> (Span, Span): split at offset relative to start, panics if offset > len
- contains_position(&self, pos: u32) -> bool: point containment [start, end)

Add `pub mod span;` and `pub use span::Span;` to lib.rs.

  <action>
Create crates/core/src/char_mapping.rs implementing bidirectional character mapping (FOUN-03):

CharMapping struct:
- Field: alignments: Vec<(u32, u32)> sorted by original position
- Each entry: (original_pos, normalized_pos)

Methods:
- new(alignments: Vec<(u32, u32)>) -> Self: debug_assert sorted
- identity(len: u32) -> Self: (i, i) for all i in 0..len
- to_normalized(&self, original_pos: u32) -> Result<u32, NormalizeError>: binary search lookup
- to_original(&self, normalized_pos: u32) -> Result<u32, NormalizeError>: search by normalized position (monotonic)
- compose(&self, other: &CharMapping) -> Result<CharMapping, NormalizeError>: chain A->B with B->C to get A->C
- len(), is_empty(), alignments(): accessors

For both to_normalized and to_original:
- Binary search by key
- On inexact match, return nearest lower bound
- On empty mapping, return NormalizeError::InvalidPosition

Add `pub mod char_mapping;` and `pub use char_mapping::CharMapping;` to lib.rs.

Unit tests:
- identity_round_trips
- simple_insertion_mapping (a->a_, b shifted)
- compose_two_mappings (shift+shift = double shift)
- compose_three_mappings_round_trip (SUCCESS CRITERION 3)
- empty_mapping_errors

Property tests (proptest):
- identity_always_round_trips (any len, any pos within len)
- compose_with_identity_is_noop (arbitrary mapping composed with identity)

IMPORTANT: The compose_three_mappings_round_trip test must be explicit and robust -- it validates success criterion 3.
