<feature>
  <name>Histogram Diff Algorithm</name>
  <files>crates/core/src/diff/histogram.rs, crates/core/src/diff/mod.rs</files>
  <behavior>
    Histogram diff algorithm operating on &amp;[u32] token index slices.

    **Struct:** `Histogram` with fields:
    - `chain_limit: usize` -- max occurrence count for LCS candidates. Default = 64.
    - `use_common_affixes: bool` -- common prefix/suffix optimization. Default = true.
    - `myers_threshold: Option&lt;usize&gt;` -- D-threshold for internal Myers fallback. Default = Some(4096).

    **Constructors:**
    - `Histogram::new()` -- chain_limit=64, affixes=true, myers_threshold=Some(4096)
    - `Histogram::with_chain_limit(limit: usize)` -- custom chain limit
    - `Histogram::without_common_affixes(mut self) -> Self` -- builder, returns self

    **Implement `Default` for `Histogram`:** same as `Histogram::new()`.

    **Algorithm (iterative with explicit stack, NOT recursive):**
    1. If use_common_affixes: strip common prefix/suffix, note prefix_len and suffix_len for later offset adjustment.
    2. Initialize explicit work stack: `Vec&lt;Region&gt;` where `Region { src_start, src_end, tgt_start, tgt_end }`.
    3. Push initial inner region onto stack.
    4. Initialize results collector: `Vec&lt;EditOperation&gt;`.
    5. Process regions from stack (LIFO):
       a. Pop region. If empty (src_start == src_end AND tgt_start == tgt_end): continue.
       b. If only source is non-empty: emit Delete for the range. Continue.
       c. If only target is non-empty: emit Insert for the range. Continue.
       d. Count occurrences of each token value in source region: `HashMap&lt;u32, usize&gt;`.
       e. Scan target region. For each token that exists in source with occurrence count &lt;= chain_limit, record as LCS candidate with its occurrence count. Track the candidate with the LOWEST count (rarest token = best split point).
       f. If no candidate found (all tokens exceed chain_limit or no shared tokens): fall back to Myers for this region. Instantiate `Myers::new()` (or with configured threshold). Run compute on the sub-slices. Offset results by region start. Collect operations.
       g. If candidate found at source position `s_pos` and target position `t_pos`:
          - Emit Equal for the split token: `Equal(s_pos..s_pos+1, t_pos..t_pos+1)`
          - Push the AFTER region: `Region(s_pos+1..src_end, t_pos+1..tgt_end)`
          - Push the BEFORE region: `Region(src_start..s_pos, tgt_start..t_pos)`
          - (Push after first so before is processed first -- LIFO order)
    6. After all regions processed: sort operations by (source_start, target_start) to ensure correct ordering.
    7. Merge adjacent Delete+Insert into Replace (same logic as Myers).
    8. Offset all operations by prefix_len.
    9. Prepend prefix Equal, append suffix Equal.
    10. Track is_approximate: true if any Myers fallback region was approximate.
    11. Progress: call callback every 32 region pops with estimated progress = regions_processed / estimated_total. Estimated_total starts at 1 and grows as regions are pushed. Check for cancellation.

    **Test cases:**
    - `[] vs []` -> `[]`
    - `[0] vs [0]` -> `[Equal(0..1, 0..1)]`
    - `[0] vs [1]` -> `[Replace(0..1, 0..1)]`
    - `[0,1,2] vs [0,1,2]` -> all Equal
    - `[0,1,2] vs [0,3,2]` -> `Equal, Replace, Equal`
    - Token IDs for "the cat sat" vs "the dog sat on the mat" -> equivalent result to Myers
    - Repetitive text: `[0,0,0,1,0,0,0]` vs `[0,0,0,2,0,0,0]` -- unique elements `1` and `2` are best split candidates (occurrence=1), should produce `Equal(0..3,0..3), Replace(3..4,3..4), Equal(4..7,4..7)`
    - Chain limit exceeded: set chain_limit=1, input where all tokens appear 2+ times -> falls back to Myers
    - Cancellation: callback returns Break -> DiffError::Cancelled
    - Roundtrip: for each test case, verify `apply_operations(source, target, ops) == target`

    **Key correctness property:** Finding the token with lowest occurrence guarantees optimal split points for structured text. When elements repeat more than chain_limit, Myers handles the degenerate case.
  </behavior>
