  <behavior>
    Myers diff algorithm operating on &amp;[u32] token index slices.

    **Struct:** `Myers` with fields:
    - `threshold: Option&lt;usize&gt;` -- D-threshold. None = no limit. Default = `Some(4096)`.
    - `use_common_affixes: bool` -- common prefix/suffix optimization. Default = true.

    **Constructors:**
    - `Myers::new()` -- threshold=Some(4096), use_common_affixes=true
    - `Myers::with_threshold(threshold: usize)` -- Some(threshold), affixes=true
    - `Myers::without_threshold()` -- None, affixes=true
    - `Myers::without_common_affixes(mut self) -> Self` -- builder pattern, sets use_common_affixes=false, returns self

    **Implement `Default` for `Myers`:** same as `Myers::new()`.

    **Algorithm (forward Myers O(ND) with trace):**
    1. If use_common_affixes: call `strip_common_affixes()` from common.rs. Emit Equal ops for the prefix and suffix.
    2. If inner_source and inner_target are both empty after stripping: return just prefix+suffix Equal ops.
    3. Run forward Myers on inner slices:
       - `n = inner_source.len()`, `m = inner_target.len()`
       - `max_d = threshold.unwrap_or(n + m)` capped at `n + m`
       - Allocate V array: `vec![0usize; 2 * max_d + 3]` with offset indexing so V[k] is accessed as `v[(k + max_d as i64) as usize]`
       - Trace: `Vec&lt;Vec&lt;usize&gt;&gt;` storing V snapshots for each d
       - For d = 0..=max_d:
         - For k = -(d as i64)..=(d as i64) step 2:
           - Choose x: if k == -(d as i64) or (k != d as i64 and v[k-1] &lt; v[k+1]) then x = v[k+1] else x = v[k-1] + 1
           - y = x - k (as i64 arithmetic, cast to usize)
           - Extend snake: while x &lt; n and y &lt; m and inner_source[x] == inner_target[y], x += 1, y += 1
           - v[k] = x
           - If x >= n and y >= m: found the edit path at distance d. Backtrace and return.
         - Save V snapshot to trace
         - Every 32 d iterations: call progress callback with `d as f64 / max_d as f64`. If returns Break, return Err(DiffError::Cancelled).
       - If d exceeds max_d without finding path: D-threshold hit. Set is_approximate = true. Emit remaining inner tokens as a single Replace (or best-effort partial from trace).
    4. **Backtrace with first-class Replace emission:** walk backwards through the trace to reconstruct the edit path. During backtrace, when a diagonal-miss step would produce a Delete immediately followed by an Insert at contiguous indices, emit a single Replace operation instead. Replace is detected and emitted directly during backtrace construction — there is no separate post-processing merge pass. This honors the locked decision that Replace is a first-class operation emitted directly by the algorithm.
    5. **Offset adjustment:** add `prefix_len` to all source indices. Add `prefix_len` to all target indices (where prefix_len is the common prefix length from step 1). This maps inner-slice coordinates back to original token coordinates.
    6. **Concatenate:** prefix Equal (if any) + adjusted inner ops + suffix Equal (if any). The suffix Equal uses source indices `[n - suffix_len, n)` and target indices `[m - suffix_len, m)` where n/m are the original full source/target lengths.

    **Test cases (all using raw u32 slices, not ProcessedText):**
    - `[] vs []` -> `[]` (empty produces no operations)
    - `[0] vs [0]` -> `[Equal(0..1, 0..1)]`
    - `[0] vs [1]` -> `[Replace(0..1, 0..1)]`
    - `[0,1,2] vs [0,1,2]` -> single `Equal(0..3, 0..3)` or equivalent coalesced
    - `[0,1,2] vs [0,3,2]` -> `Equal(0..1,0..1), Replace(1..2,1..2), Equal(2..3,2..3)`
    - `[0,1,2] vs [0,1,2,3,4]` -> `Equal(0..3,0..3), Insert(3,3..5)`
    - `[0,1,2,3,4] vs [0,1,2]` -> `Equal(0..3,0..3), Delete(3..5,3)`
    - Token IDs for "the cat sat" [0,1,2] vs "the dog sat on the mat" [0,3,2,4,0,5]:
      -> Equal(0..1,0..1), Replace(1..2,1..2), Equal(2..3,2..3), Insert(3,3..6)
    - D-threshold: `[0,1,2,...,99]` vs `[100,101,...,199]` (100 completely different) with threshold=5 -> is_approximate=true, threshold_used=Some(5)
    - Progress callback: count calls, verify > 0 for non-trivial input
    - Cancellation: callback returns Break(()) immediately -> Err(DiffError::Cancelled)
    - Common affixes disabled: same results as with affixes (just potentially slower)
    - Roundtrip: for each test case, verify `apply_operations(source, target, ops) == target`
  </behavior>
