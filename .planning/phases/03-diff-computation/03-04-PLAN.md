fn arb_token_pair(max_len: usize) -> impl Strategy<Value = (Vec<u32>, Vec<u32>)> {
    (1..=20usize).prop_flat_map(move |vocab_size| {
        let source = prop::collection::vec(0..vocab_size as u32, 0..max_len);

        (source, target)

**Property test helper** to validate operation completeness:
```rust
fn assert_operations_complete(source_len: usize, target_len: usize, ops: &[EditOperation]) {
    // Every source index covered exactly once
    let mut src_pos = 0u32;
    let mut tgt_pos = 0u32;
    for op in ops {
        assert_eq!(op.source_start, src_pos, "Source gap at {}", src_pos);
        assert_eq!(op.target_start, tgt_pos, "Target gap at {}", tgt_pos);
        src_pos = op.source_end;
        tgt_pos = op.target_end;
    }
    assert_eq!(src_pos, source_len as u32, "Source not fully covered");
    assert_eq!(tgt_pos, target_len as u32, "Target not fully covered");
}
```

**Property tests** (all with `ProptestConfig::with_cases(1000)`):

1. **myers_roundtrip**: For all (source, target) pairs up to 200 tokens:
   - Run `Myers::new().compute(&source, &target, None).unwrap()`
   - `let reconstructed = apply_operations(&source, &target, &output.operations);`
   - `prop_assert_eq!(reconstructed, target);`

2. **histogram_roundtrip**: Same pattern with `Histogram::new()`, 1000 cases.

3. **myers_no_affixes_roundtrip**: `Myers::new().without_common_affixes()`, 1000 cases. Verify common affix optimization doesn't affect correctness.

4. **myers_operations_complete**: For all pairs, verify `assert_operations_complete()` passes. This validates the locked decision that "operations are complete and ordered -- every token is covered by exactly one operation, in sequence, no gaps."

5. **histogram_operations_complete**: Same for Histogram.

6. **equal_ops_consistent**: For all pairs and both algorithms, verify that for every Equal operation, `source[src_start..src_end]` (by u32 value) matches `target[tgt_start..tgt_end]`.

7. **statistics_consistency**: For all pairs (Myers):
   - `similarity_ratio` is in `[0.0, 1.0]`
   - `edit_distance == delete_count + insert_count + replace_count`
   - `lcs_length <= source.len().min(target.len())`
   - If source == target: `similarity_ratio == 1.0` and `edit_distance == 0`

8. **identical_inputs**: For all source vectors, `Myers::new().compute(&source, &source, None)` produces all-Equal operations.

9. **empty_inputs**: Verify `[] vs []` and `[] vs [1,2,3]` and `[1,2,3] vs []` all roundtrip correctly for both algorithms.

**Helper** to create ProcessedText from string (no normalizers, WordTokenizer):
```rust
fn process_text(input: &str) -> Arc<ProcessedText> {
    let processor = TextProcessor::new(
        vec![],
        Box::new(WordTokenizer::new()),
    );
    Arc::new(processor.process(input).unwrap())
}
```

**Integration tests:**

1. **the_cat_sat_vs_the_dog_sat** -- success criteria #2:
   - `let source = process_text("the cat sat");`
   - `let target = process_text("the dog sat on the mat");`
   - `let result = DiffComputer::new().compute(source, target, None).unwrap();`
   - Verify operation sequence by kind: first op is Equal (covers "the"), then Replace (covers "cat"->"dog"), then Equal (covers "sat"), then Insert (covers "on the mat").
   - Verify by checking `result.operations.iter().map(|op| op.kind).collect::<Vec<_>>()` equals `[Equal, Replace, Equal, Insert]`.
   - Verify roundtrip: reconstruct target tokens from source tokens + operations.

2. **histogram_equivalent** -- success criteria #3:
   - Same inputs as test 1 but with `DiffComputer::with_algorithm(Box::new(Histogram::new()))`.
   - Verify the result is correct (roundtrip passes).
   - The operation sequence may differ from Myers but the result must be valid.

3. **identical_texts**: "hello world" vs "hello world" -> all Equal, `result.statistics.similarity_ratio == 1.0`, `result.statistics.edit_distance == 0`.

4. **completely_different**: "aaa bbb ccc" vs "xxx yyy zzz" -> `result.statistics.similarity_ratio == 0.0`, all Replace.

5. **empty_vs_nonempty**: Process "" and "hello world". Handle gracefully (empty text may produce 0 tokens -- verify DiffComputer handles 0-length token slices without panic). If source has 0 tokens and target has N tokens, result should have all Insert operations.

6. **statistics_validation**: for "the cat sat" vs "the dog sat on the mat":
   - `equal_count > 0` (at least "the" and "sat")
   - `replace_count > 0` ("cat" -> "dog")
   - `insert_count > 0` ("on the mat")
   - `similarity_ratio` is between 0.0 and 1.0 exclusive
   - `lcs_length >= 2` (at least "the" and "sat" tokens)

7. **hunks_test**: create a diff with a long equal region, one change, long equal region. Verify `result.hunks(1)` returns one hunk centered on the change. Verify `result.hunks(0)` returns just the change operations.

8. **d_threshold_safety** -- success criteria #5 (generous bound):
   - Generate two completely different 10K-length u32 sequences: `(0..10000).collect()` vs `(10000..20000).collect()`.
   - Run `Myers::with_threshold(100).compute(&source, &target, None)`.
   - Assert returns Ok.
   - Assert `output.is_approximate == true`.
   - Assert `output.threshold_used == Some(100)`.
   - Use `std::time::Instant` to measure: assert completes in < 5 seconds (generous -- actual should be <100ms).

9. **cancellation** -- locked decision validation:
   - Set up progress callback: `let mut called = false; |_progress| { called = true; ControlFlow::Break(()) }`.
   - Run on a non-trivial input (100 different tokens).
   - Assert result is `Err(DiffError::Cancelled)`.
   - Assert `called == true`.

10. **hashmap_storable** -- success criteria #6:
    - `let result = DiffComputer::new().compute(source, target, None).unwrap();`
    - `let mut map: HashMap<String, _> = HashMap::new();`
    - `map.insert("test".to_string(), result.clone());`
    - `assert_eq!(map["test"].operations, result.operations);`

11. **metadata_algorithm_name**:
    - `DiffComputer::new()` -> `result.metadata.algorithm_name == "myers"`
    - `DiffComputer::with_algorithm(Box::new(Histogram::new()))` -> `result.metadata.algorithm_name == "histogram"`

12. **is_approximate_flag**: normal diff -> `result.is_approximate() == false`. Threshold-hit diff -> `result.is_approximate() == true`.
