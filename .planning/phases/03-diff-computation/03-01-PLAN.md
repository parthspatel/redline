**`diff/common.rs`:**

1. `build_token_indices` function -- resolves cross-TextStore token comparison (CRITICAL per research pitfall #1):
```rust
pub fn build_token_indices(
    source_tokens: &[Token],
    source_store: &TextStore,
    target_tokens: &[Token],
    target_store: &TextStore,
) -> (Vec<u32>, Vec<u32>)
```
- Creates a `hashbrown::HashMap<&str, u32>` intern map with `next_id: u32 = 0`.
- For each token in `source_tokens`: resolve `source_store.resolve(token.text_id).unwrap()` to get `&str`, intern into map (if not present, assign `next_id` and increment), push the u32 ID to source_ids vec.
- For each token in `target_tokens`: same process using `target_store`.
- Returns `(source_ids, target_ids)` where tokens with the same text get the same u32 ID regardless of which TextStore they came from.
- Note: `.unwrap()` on resolve is safe because Token StringIds are created by TextProcessor which guarantees valid IDs.

2. `strip_common_affixes` function:
```rust
pub fn strip_common_affixes<'a>(
    source: &'a [u32],
    target: &'a [u32],
) -> (usize, usize, &'a [u32], &'a [u32])
```
- Returns `(prefix_len, suffix_len, inner_source, inner_target)`.
- prefix_len: `source.iter().zip(target.iter()).take_while(|(a,b)| a == b).count()`.
- Then slice: `source_rest = &source[prefix_len..]`, `target_rest = &target[prefix_len..]`.
- suffix_len: `source_rest.iter().rev().zip(target_rest.iter().rev()).take_while(|(a,b)| a == b).count()`.
- inner_source: `&source_rest[..source_rest.len() - suffix_len]`.
- inner_target: `&target_rest[..target_rest.len() - suffix_len]`.
- Handle edge case: if prefix_len consumes everything, suffix_len is 0.

3. `apply_operations` function (for property test roundtrip verification):
```rust
pub fn apply_operations(source: &[u32], target: &[u32], ops: &[EditOperation]) -> Vec<u32>
```
- Reconstructs the target from source + target + operations.
- For each op:
  - Equal: copy `source[op.source_start as usize..op.source_end as usize]` to result
  - Delete: skip (nothing added to result)
  - Insert: copy `target[op.target_start as usize..op.target_end as usize]` to result
  - Replace: copy `target[op.target_start as usize..op.target_end as usize]` to result (same as Insert for reconstruction)
- Returns the reconstructed Vec<u32>.

- Derive `Debug, Clone`.

`DiffStatistics::from_operations(ops: &[EditOperation], source_len: usize, target_len: usize) -> Self`:
- Single pass: count each EditKind. For Equal ops, accumulate `op.source_len()` into lcs_length.
- `edit_distance = delete_count + insert_count + replace_count`
- `similarity_ratio = if source_len + target_len == 0 { 1.0 } else { (2.0 * lcs_length as f64) / (source_len + target_len) as f64 }`
- `compression_ratio = if source_len == 0 { if target_len == 0 { 1.0 } else { f64::INFINITY } } else { target_len as f64 / source_len as f64 }`
- `change_density`: partition ops into 10 windows (or fewer if < 10 ops). For each window: density = (number of non-Equal ops in window) / (total ops in window). Use `let window_size = (ops.len() + 9) / 10; ops.chunks(window_size.max(1)).map(|chunk| { let non_equal = chunk.iter().filter(|op| op.kind != EditKind::Equal).count(); non_equal as f64 / chunk.len() as f64 }).collect()`. If ops is empty, change_density is empty vec.
