- `pub const LITERARY_PROSE: &str` — Grade level ~8, Flesch 60-70. Use mixed sentence lengths, some 2-3 syllable words. - `pub const TECHNICAL_PROSE: &str` — Grade level ~12, Flesch 30-50. Use domain terminology, longer sentences. Example style: "The algorithm employs a dynamic programming approach to compute the minimum edit distance between two sequences. Each cell in the matrix represents the optimal alignment cost, considering insertions, deletions, and substitutions. This computational framework enables efficient comparison of arbitrarily long input strings."

- `pub const ACADEMIC_PROSE: &str` — Grade level ~16, Flesch <30. Use polysyllabic jargon, complex syntax. Example style: "The epistemological implications of computational linguistics necessitate rigorous examination of morphosyntactic representations within probabilistic frameworks.
