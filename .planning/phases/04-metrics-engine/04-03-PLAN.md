  <behavior>
    **ParagraphCountMetric** (id: "paragraph_count"):
    - Count `\n\n` sequences in `original`, then +1 -> Integer
    - "Hello\n\nWorld" -> Integer(2)
    - "No paragraphs" -> Integer(1)
    - Empty -> Integer(1) (one paragraph even if empty)

    **LineCountMetric** (id: "line_count"):
    - Count `\n` in `original`, then +1 -> Integer
    - "Hello\nWorld\nFoo" -> Integer(3)
    - "Single line" -> Integer(1)
    - Empty -> Integer(1)

    **LetterCountMetric** (id: "letter_count"):
    - Count chars where `char::is_alphabetic()` -> Integer
    - "Hello 123!" -> Integer(5)
    - Handles Unicode letters

    **DigitCountMetric** (id: "digit_count"):
    - Count chars where `char::is_ascii_digit()` -> Integer
    - "Hello 123!" -> Integer(3)

    **WhitespaceCountMetric** (id: "whitespace_count"):
    - Count chars where `char::is_whitespace()` -> Integer
    - "Hello World" -> Integer(1)
    - Includes tabs, newlines

    **PunctuationCountMetric** (id: "punctuation_count"):
    - Count chars where `char::is_ascii_punctuation()` -> Integer
    - "Hello, world!" -> Integer(2)

    All metrics: zero dependencies, cost 0.01, reject Pairwise input.

    **Engine integration tests** (in crates/core/tests/metrics_engine.rs):
    - Register all 11 count metrics in a MetricRegistry.
    - Create MetricsEngine with cache.
    - Process "The quick brown fox jumps over the lazy dog." through TextProcessor.
    - Call engine.get("word_count"), engine.get("char_count"), etc. -- verify values.
    - Call engine.get("word_count") again -- verify cache hit (cache_len should not increase).
    - Call engine.get_many with all 11 metric IDs -- verify HashMap has all entries.
  </behavior>
