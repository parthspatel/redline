  <behavior>
    **AvgWordLengthMetric** (id: "avg_word_length"):
    - Dependencies: `["char_count", "word_count"]`
    - Formula: `char_count as f64 / word_count as f64` -> Float
    - word_count=0 -> Float(0.0)

    **AvgSentenceLengthMetric** (id: "avg_sentence_length"):
    - Dependencies: `["word_count", "sentence_count"]`
    - Formula: `word_count as f64 / sentence_count as f64` -> Float
    - sentence_count=0 -> Float(0.0)

    **VocabularyRichnessMetric** (id: "vocabulary_richness"):
    - Dependencies: `["unique_word_count", "word_count"]`
    - Formula: `unique_word_count as f64 / word_count as f64` -> Float (Type-Token Ratio)
    - word_count=0 -> Float(0.0)

    **LexicalDensityMetric** (id: "lexical_density"):
    - Dependencies: `["word_count"]`
    - Also reads tokens from `input` to classify content vs function words.
    - A content word is any word NOT in a curated ~150-word English function word list (articles, prepositions, conjunctions, pronouns, determiners, auxiliary verbs).
    - Store function word list as a static slice or lazy-initialized HashSet.
    - Formula: `content_words as f64 / word_count as f64` -> Float
    - word_count=0 -> Float(0.0)

    **FleschReadingEaseMetric** (id: "flesch_reading_ease"):
    - Dependencies: `["word_count", "sentence_count", "syllable_count"]`
    - Formula: `206.835 - 1.015 * (words / sentences) - 84.6 * (syllables / words)` -> Float
    - words=0 or sentences=0 -> Float(0.0)

    **All readability metrics:**
    - `dependency_kind()` returns `DependencyKind::Static`
    - `cost()` returns `0.1`
    - Reject Pairwise input with `MetricError::InvalidInput`
    - Use epsilon comparison in tests: `(actual - expected).abs() < 0.01`

    **Dependency failure handling:**
    - If any required dependency is `Unavailable` or missing, return `Err(MetricError::DependencyUnavailable("dep_name"))`.
    - The engine catches this and converts to `MetricValue::Unavailable`.
  </behavior>

    4. Update `metrics/mod.rs` to ensure `pub mod readability;` is declared.
  </implementation>
</feature>
