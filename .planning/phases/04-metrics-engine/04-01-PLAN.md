    **1. Create `crates/core/src/metrics/cache.rs`:**

    - `ContentHash(u64)` -- derive `Debug, Clone, Copy, PartialEq, Eq, Hash`.
      - `ContentHash::of_single(text: &ProcessedText) -> Self`: hash `text.original` + `text.normalized` + `text.tokens.len()` using `hashbrown::DefaultHashBuilder::default().build_hasher()` via `core::hash::{Hash, Hasher}`.
      - `ContentHash::of_pair(source: &ProcessedText, target: &ProcessedText) -> Self`: hash both texts' original + normalized fields.

    - `CacheKey` struct with `content_hash: ContentHash` and `metric_id: String`. Derive `Debug, Clone, PartialEq, Eq, Hash`.

    - `MetricCache` struct wrapping `lru::LruCache<CacheKey, MetricValue>`.
      - `new(capacity: usize) -> Self`: create LruCache with `NonZeroUsize::new(capacity).expect("cache capacity must be > 0")`.
      - `get(&mut self, key: &CacheKey) -> Option<MetricValue>`: returns cloned value. Uses `self.inner.get(key).cloned()`.
      - `put(&mut self, key: CacheKey, value: MetricValue)`: insert into LRU cache.
      - `len(&self) -> usize`
      - `clear(&mut self)`

    **2. Create `crates/core/src/metrics/engine.rs`:**

    - `MetricsEngine` struct:
      - `registry: MetricRegistry`
      - `cache: Option<RefCell<MetricCache>>`

    - Constructors:
      - `MetricsEngine::new(registry: MetricRegistry) -> Self` -- no cache.
      - `MetricsEngine::with_cache(registry: MetricRegistry, capacity: usize) -> Self` -- cache enabled.
      - `MetricsEngine::with_default_cache(registry: MetricRegistry) -> Self` -- cache with capacity 256.

    - Core methods:
      - `pub fn get(&self, id: &str, input: &MetricInput<'_>) -> MetricValue`:
        Uses a private recursive helper with a `RefCell<HashSet<String>>` for cycle detection.

        Private helper `fn compute_metric(&self, id: &str, input: &MetricInput<'_>, computing: &RefCell<HashSet<String>>) -> MetricValue`:
        1. Build cache key from ContentHash + metric_id.
        2. Check cache -- if hit, return cached value.
        3. Check cycle -- if `computing` contains id, return `MetricValue::Unavailable`.
        4. Insert id into computing set.
        5. Look up metric in registry. If None, return `Unavailable`.
        6. Resolve static dependencies recursively.
        7. Resolve dynamic dependencies recursively.
        8. Collect resolved deps into `HashMap<String, MetricValue>`.
        9. Call `metric.compute(input, &deps)`. On `Ok(value)`, cache and return. On `Err`, cache `Unavailable`, return `Unavailable`.
        10. Remove id from computing set (cleanup).

        Use `RefCell<MetricCache>` for interior mutability so `get()` takes `&self`.

      - `pub fn get_many(&self, ids: &[&str], input: &MetricInput<'_>) -> HashMap<String, MetricValue>`
      - `pub fn registry(&self) -> &MetricRegistry`
      - `pub fn clear_cache(&self)`
      - `pub fn cache_len(&self) -> usize`

    **Tests (in-module):**
    - ContentHash: same text produces same hash, different text produces different hash.
    - MetricCache: put/get works, LRU eviction at capacity, clear works.
    - MetricsEngine: simple metric returns correct value, cache hit on second call, cycle detection returns Unavailable, get_many works.
