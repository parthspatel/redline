  <behavior>
    **FleschKincaidGradeMetric** (id: "flesch_kincaid_grade"):
    - Dependencies: `["word_count", "sentence_count", "syllable_count"]`
    - Formula: `0.39 * (words / sentences) + 11.8 * (syllables / words) - 15.59` -> Float
    - words=0 or sentences=0 -> Float(0.0)

    **GunningFogMetric** (id: "gunning_fog"):
    - Dependencies: `["word_count", "sentence_count"]`
    - Also reads tokens from `input` to count complex words (words with 3+ syllables, using count_syllables helper from counts module).
    - Formula: `0.4 * (words/sentences + 100 * (complex_words/words))` -> Float
    - words=0 or sentences=0 -> Float(0.0)

    **SmogIndexMetric** (id: "smog_index"):
    - Dependencies: `["sentence_count"]`
    - Also reads tokens from input to count polysyllabic words (3+ syllables).
    - Formula: `1.0430 * (polysyllables as f64 * 30.0 / sentences as f64).sqrt() + 3.1291` -> Float
    - sentences=0 -> Float(0.0)

    **ColemanLiauMetric** (id: "coleman_liau"):
    - Dependencies: `["letter_count", "word_count", "sentence_count"]`
    - Formula: L = `letter_count * 100 / word_count`, S = `sentence_count * 100 / word_count`. Result = `0.0588 * L - 0.296 * S - 15.8` -> Float
    - words=0 -> Float(0.0)

    **AriMetric** (id: "ari"):
    - Dependencies: `["char_count", "word_count", "sentence_count"]`
    - Formula: `4.71 * (chars / words) + 0.5 * (words / sentences) - 21.43` -> Float
    - words=0 or sentences=0 -> Float(0.0)

    **All metrics:** cost() = 0.1, reject Pairwise input, epsilon-tolerant float comparison in tests.
