  <name>Pairwise Set/Vector Metrics (7 metrics)</name>
  <files>

  </files>
  <behavior>
    All pairwise metrics:
    - Accept `MetricInput::Pairwise(source, target)` only.
    - Return `Err(MetricError::InvalidInput(...))` for `MetricInput::Single`.
    - Zero static dependencies (operate directly on input tokens).
    - `cost()` = 0.1 for set-based, 0.01 for simple diffs.

    **JaccardSimilarityMetric** (id: "jaccard_similarity"):
    - Build sets of `StringId` from source.tokens and target.tokens.
    - `|intersection| / |union|` -> Float
    - Both empty -> Float(1.0) (identical empty sets)

    **CosineSimilarityMetric** (id: "cosine_similarity"):
    - Build frequency vectors (HashMap<StringId, usize>) from source and target tokens.
    - Dot product / (magnitude_source * magnitude_target) -> Float
    - Both empty -> Float(1.0)
    - Orthogonal texts (no shared tokens) -> Float(0.0)

    **DiceCoefficientMetric** (id: "dice_coefficient"):
    - `2 * |intersection| / (|A| + |B|)` on StringId sets -> Float
    - Both empty -> Float(1.0)

    **OverlapCoefficientMetric** (id: "overlap_coefficient"):
    - `|intersection| / min(|A|, |B|)` on StringId sets -> Float
    - Both empty -> Float(1.0); one empty -> Float(0.0)

    **LengthRatioMetric** (id: "length_ratio"):
    - `target.tokens.len() as f64 / source.tokens.len() as f64` -> Float
    - source.tokens empty -> Float(0.0)

    **WordCountDiffMetric** (id: "word_count_diff"):
    - `target.tokens.len() as i64 - source.tokens.len() as i64` -> Integer

    **CharCountDiffMetric** (id: "char_count_diff"):
    - `target.original.len() as i64 - source.original.len() as i64` -> Integer

    **Property tests:**
    - All similarity metrics in [0.0, 1.0]
    - jaccard(a,a)=1.0, cosine(a,a)=1.0
    - Symmetry: jaccard(a,b) == jaccard(b,a)
  </behavior>
  <implementation>
    1. Create `similarity/mod.rs` with module declarations and re-exports.
    2. Each metric in its own file.
    3. Set operations use `HashSet<StringId>` from `hashbrown`.
    4. Helper to create two ProcessedText instances for testing.
  </implementation>
</feature>
