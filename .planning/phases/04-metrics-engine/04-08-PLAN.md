  <action>
    **1. ReadabilityDeltaMetric** (id: "readability_delta"):
    - Pairwise metric computing the difference in flesch_reading_ease between two texts.
    - Since the engine can't automatically compute single-text metrics on each text of a pairwise input, this metric computes the readability formula directly from both texts (reading tokens, counting syllables, counting sentences from each text independently).
    - No engine dependencies -- zero static_dependencies.
    - Formula: compute flesch_reading_ease for target, compute for source, return `Float(target_fre - source_fre)`.
    - Returns Float (can be negative).
    - Cost: 0.3

    **2. GradeLevelDeltaMetric** (id: "grade_level_delta"):
    - Same approach for flesch_kincaid_grade.
    - No dependencies, self-contained computation.
    - Returns Float.

    **3. SimilarityRatioMetric** (id: "similarity_ratio"):
    - Computes similarity ratio between two token sequences using LCS.
    - `similarity = 2 * lcs_length / (source.len() + target.len())` -> Float
    - LCS via DP with two-row optimization.
    - Both empty -> Float(1.0).
    - No dependencies.
    - Cost: 0.5

    **4. Update similarity/mod.rs** with new module declarations and re-exports.

    **5. Create `crates/core/src/metrics/builtins.rs`:**
    - `pub fn register_builtins(registry: &mut MetricRegistry) -> Result<(), MetricError>`
    - Registers all count metrics (11), then all readability metrics (10), then all pairwise metrics (15).
    - Registration order matters: counts first (no deps), then readability (depend on counts), then pairwise (some depend on jaro).
    - Calls `registry.validate()` at the end to verify no cycles or missing deps.

    **6. Update `crates/core/src/metrics/mod.rs`:**
    - Ensure `pub use builtins::register_builtins;` is re-exported.
  </action>

    `cargo test --lib metrics` passes.
  </verify>
