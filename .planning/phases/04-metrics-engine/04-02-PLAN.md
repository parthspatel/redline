  <behavior>
    Each metric is a struct implementing the `Metric` trait with zero static dependencies.

    **WordCountMetric** (id: "word_count"):
    - `tokens.len() as i64` -> Integer
    - Empty text -> Integer(0)

    **CharCountMetric** (id: "char_count"):
    - `original.chars().count() as i64` -> Integer
    - Counts Unicode chars (not bytes). "cafe\u{0301}" has 5 chars.

    **ByteCountMetric** (id: "byte_count"):
    - `original.len() as i64` -> Integer (UTF-8 byte length)

    **SentenceCountMetric** (id: "sentence_count"):
    - Count occurrences of `.`, `!`, `?` in `original` text -> Integer
    - Handle abbreviations minimally (consecutive sentence-enders count as one: "..." = 1)
    - Empty text -> Integer(0)
    - "Hello." -> Integer(1)
    - "Hello! How are you? Fine." -> Integer(3)

    **SyllableCountMetric** (id: "syllable_count"):
    - Sum `count_syllables(word)` for each token.
    - `count_syllables` heuristic (~90-95% accuracy):
      1. Lowercase the word, strip non-alpha chars
      2. Count vowel groups (a, e, i, o, u, y -- y only when not first char)
      3. Subtract 1 for silent-e (word ends in 'e' but not "le")
      4. Handle special suffixes: -ed (usually not a syllable unless preceded by t/d), -es
      5. Minimum 1 syllable per word
    - "hello" -> 2, "the" -> 1, "beautiful" -> 3, "a" -> 1
    - Empty text -> Integer(0)

    **UniqueWordCountMetric** (id: "unique_word_count"):
    - Collect `token.text_id` values into a HashSet, return `.len() as i64` -> Integer
    - "the cat the dog" -> 3 (the, cat, dog)

    **All metrics:**
    - `static_dependencies()` returns `&[]`
    - `dependency_kind()` returns `DependencyKind::Static`
    - `cost()` returns `0.01` (trivial)
    - When given `MetricInput::Pairwise(_, _)`, return `Err(MetricError::InvalidInput(...))`

    **Test cases (known values):**
    - "The quick brown fox jumps over the lazy dog" -> word_count=9, char_count=43, sentence_count=0 (no period), unique_word_count=8 (the appears twice)
    - "Hello world." -> word_count=2, sentence_count=1
    - "" (empty) -> all counts = 0
    - Unicode: "cafe\u{0301}" -> char_count=5, byte_count=6

    **Property tests:**
    - For any ProcessedText: word_count >= 0, char_count >= 0, unique_word_count <= word_count
    - syllable_count >= word_count (every word has at least 1 syllable, but only if word_count > 0)
  </behavior>
