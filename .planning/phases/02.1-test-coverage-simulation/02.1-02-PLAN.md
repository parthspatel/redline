# Plan 02.1-02: Normalizer Edge Case Tests

**Objective:** Add edge case tests to all 6 normalizers focusing on boundary conditions, Unicode edge cases, CharMapping correctness, and error paths.

## must_haves

- Each normalizer tested with: single char input, all-removed input (error path), multi-byte Unicode char that changes byte length
- CharMapping round-trip verified for each normalizer with non-trivial input
- Lowercase tested with chars that change byte length (Ⱥ→ⱥ, İ→i̇)
- WhitespaceNormalizer tested with: only whitespace, mixed tab/newline/space, Unicode whitespace (NBSP, em-space)
- UnicodeNormalizer tested with: all 4 forms (NFC, NFD, NFKC, NFKD), precomposed vs decomposed round-trip
- Diacritics tested with: Vietnamese (multiple stacked diacritics), text with zero diacritics (noop)
- Punctuation/Digits tested with: Unicode punctuation/digits NOT removed (only ASCII removed), mixed

## Tasks

<task id="1" type="execute">
**Add edge case tests to all 6 normalizers**

Read each normalizer file first, then add tests to existing `#[cfg(test)]` blocks.

**Lowercase (lowercase.rs):**
- Single char: `"A"` → `"a"` with correct mapping
- Byte-length change: `"Ⱥ"` (2 bytes) → `"ⱥ"` (3 bytes) — verify mapping.original_len() == 2
- Byte-length change: `"İ"` (2 bytes) → `"i̇"` (3 bytes, i + combining dot) — verify CharMapping
- All-lowercase input (noop content but mapping still built): `"hello"` → `"hello"`
- Single Unicode char: `"Ω"` → `"ω"` with mapping positions
- Mixed scripts: Cyrillic `"ПРИВЕТ"` lowercased correctly

**WhitespaceNormalizer (whitespace.rs):**
- Single space: `" "` — should return error (empty after trim? or single space?)
- Only whitespace: `"   \t\n  "` — verify EmptyInput error
- Unicode whitespace: `"hello\u{00A0}world"` (NBSP) — collapsed to single space
- Tab + newline: `"hello\t\nworld"` — normalized
- Leading/trailing whitespace: `"  hello  "` — verify trimming behavior
- Triple+ space collapse: `"a     b"` → `"a b"` with correct CharMapping

**UnicodeNormalizer (unicode.rs):**
- Single precomposed char NFC: `"é"` (U+00E9) stays as `"é"`
- Decomposed to NFC: `"é"` (e + U+0301) → `"é"` (U+00E9)
- NFD form: precomposed → decomposed
- NFKC compatibility: `"ﬁ"` (U+FB01) → `"fi"` (2 chars)
- NFKD compatibility: same as above but decomposed
- Already normalized input (noop): ASCII text through NFC

**RemoveDiacritics (diacritics.rs):**
- No diacritics present: `"hello"` → `"hello"` (noop CharMapping)
- Single accented char: `"é"` → `"e"` with mapping
- Vietnamese: `"Việt"` — multiple stacked marks removed
- Mixed: `"café résumé"` — only accented chars changed
- All diacritics: input that becomes empty after removal → EmptyInput error

**RemovePunctuation (punctuation.rs):**
- Unicode punctuation preserved: `"«hello»"` — `«»` are NOT ASCII punctuation, kept
- Only ASCII punctuation: `"!@#$"` → EmptyInput error
- Mixed: `"hello, world!"` → `"hello world"` (note: space preserved)
- Single punctuation char: `"."` → EmptyInput error

**RemoveDigits (digits.rs):**
- Unicode digits preserved: `"hello①②③"` — circled digits NOT removed
- Only ASCII digits: `"12345"` → EmptyInput error
- Mixed: `"abc123def"` → `"abcdef"` with correct mapping
- Single digit: `"5"` → EmptyInput error
