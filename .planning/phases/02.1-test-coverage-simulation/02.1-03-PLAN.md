# Plan 02.1-03: Tokenizer and Process Edge Case Tests

**Objective:** Add edge case tests to all 5 tokenizers and TextProcessor, focusing on boundary conditions, Unicode edge cases, and error paths.

## must_haves

- Each tokenizer tested with: single char, empty string, whitespace-only, long input, ZWJ emoji
- CharTokenizer: multi-byte graphemes produce correct spans with non-identity CharMapping
- WordTokenizer: single word (no spaces), punctuation-only, trailing space
- SentenceTokenizer: no sentence boundaries, single sentence, abbreviations
- NGram tokenizers: n=1 (degenerate), n > token count, n=0 error
- TextProcessor: duplicate normalizer names error, empty normalizer list, process called twice

## Tasks

<task id="1" type="execute">
**Add edge case tests to all 5 tokenizers and TextProcessor**

Read each file first, then add tests to existing `#[cfg(test)]` blocks.

**CharTokenizer (char_tokenizer.rs):**
- Single ASCII char: `"a"` → 1 token with span 0..1
- Single multi-byte char: `"é"` → 1 token with span 0..2
- ZWJ emoji: `"👨‍👩‍👧"` → 1 token (single grapheme cluster)
- Text with non-identity CharMapping: use a mapping from Lowercase on `"Ⱥ"` (2→3 byte change), verify spans reference original positions
- Empty string: returns empty Vec
- Very long string: 1000 ASCII chars → 1000 tokens

**WordTokenizer (word.rs):**
- Single word no spaces: `"hello"` → 1 token
- Punctuation-only: `"!!!"` → 1 token (punctuation stays with words)
- Trailing space: `"hello "` → 1 token (trailing space is whitespace, not a word)
- Leading space: `" hello"` → 1 token
- Multiple spaces: `"a  b  c"` → 3 tokens
- Tab separator: `"hello\tworld"` → 2 tokens
- Empty string: returns empty Vec
- Non-identity CharMapping: use mapping from WhitespaceNormalizer, verify spans

**SentenceTokenizer (sentence.rs):**
- No sentence boundary: `"hello world"` → 1 sentence token
- Empty string: returns empty Vec
- Whitespace-only: `"   "` → empty (no alphanumeric content)
- Multiple sentences: `"Hello. World."` → 2 tokens
- Abbreviation edge case: `"Dr. Smith"` → verify UAX#29 behavior (may split)
- CJK period: `"你好。世界。"` → verify sentence boundary at fullwidth period
- Single word: `"Hello"` → 1 token

**WordNGramTokenizer (word_ngram.rs):**
- n=1: equivalent to base tokenizer output
- n > token_count: returns empty Vec (documented behavior)
- n=2 on 2 tokens: returns exactly 1 bigram
- n=2 on 1 token: returns empty Vec
- Verify space-joined text: bigram of "hello" + "world" = "hello world"

**CharNGramTokenizer (char_ngram.rs):**
- n=1: equivalent to base CharTokenizer
- n > grapheme_count: returns empty Vec
- n=2 on single char: returns empty Vec
- Multi-byte n-grams: `"éà"` with n=2 → 1 token with correct span
- ZWJ emoji in n-grams: verify grapheme-aware slicing

**TextProcessor (process/mod.rs):**
- Empty normalizer list: allowed, tokenizer runs on raw input
- Duplicate normalizer names: returns ProcessError
- Process empty string: returns EmptyInput error
- Process single char: works end-to-end
- Process with ExecutionMode::Minimal: skips high-cost normalizers
- Verify layers count matches normalizer count
- Verify composed_mapping is None when no normalizers
- Verify composed_mapping is Some when normalizers present
