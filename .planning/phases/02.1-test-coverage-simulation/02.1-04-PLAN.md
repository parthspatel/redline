# Plan 02.1-04: Normalizer x Tokenizer Integration Matrix

**Objective:** Create a comprehensive integration test file that exercises semantically meaningful normalizer-tokenizer combinations through the TextProcessor pipeline, verifying correct output and CharMapping integrity.

## must_haves

- At least 20 normalizer-tokenizer combination tests
- Each test verifies: process succeeds, tokens non-empty, spans valid, CharMapping present
- Multi-normalizer chains (2-3 normalizers) tested with each tokenizer
- At least one test per tokenizer with at least 3 different normalizer combos
- Unicode input tested with at least 5 different combos

Semantically meaningful combinations to test:

**CharTokenizer combos (~6 tests):**

5. RemovePunctuation → CharTokenizer (punctuation stripped)
6. Lowercase + Whitespace + UnicodeNFC → CharTokenizer (3-normalizer chain)

**WordTokenizer combos (~6 tests):**
1. Lowercase → WordTokenizer (most common real-world combo)
2. Lowercase + Whitespace → WordTokenizer (the standard pipeline)
3. RemovePunctuation + Lowercase → WordTokenizer (clean words)
4. RemoveDigits + Lowercase → WordTokenizer (text-only words)
5. UnicodeNFC + Lowercase + Whitespace → WordTokenizer (full cleanup)
6. RemoveDiacritics + Lowercase → WordTokenizer (accent-insensitive words)

**SentenceTokenizer combos (~4 tests):**
1. Lowercase → SentenceTokenizer (basic)

**Each test should verify:**
```rust
fn assert_pipeline_valid(input: &str, normalizers: Vec<Box<dyn Normalizer>>, tokenizer: Box<dyn Tokenizer>) {
    let processor = TextProcessor::new(normalizers, tokenizer, ExecutionMode::All).unwrap();
    let result = processor.process(input).unwrap();
    
    // Basic validity
    assert!(!result.tokens.is_empty(), "tokens should not be empty for non-trivial input");
    assert!(!result.normalized.is_empty());
    
    // Span validity: all spans within original text bounds
    for tok in &result.tokens {
        let start = tok.span.start() as usize;
        let end = tok.span.end() as usize;
        assert!(start <= end, "span start > end");
        assert!(end <= input.len(), "span end {} > input len {}", end, input.len());
    }
    
    // CharMapping present when normalizers used
    if !result.layers.is_empty() {
        assert!(result.composed_mapping.is_some());
    }
    
    // Layers match normalizer count
    assert!(result.layers.len() > 0);
}
```
