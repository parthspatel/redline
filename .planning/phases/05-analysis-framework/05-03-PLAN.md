    ```rust
    pub struct HeuristicScoring;

    impl ScoringBackend for HeuristicScoring {
        fn name(&self) -> &str {
            "heuristic_jaccard"
        }

        fn score(&self, source_tokens: &[&str], target_tokens: &[&str]) -> f64 {
            if source_tokens.is_empty() && target_tokens.is_empty() {
                return 1.0;
            }
            if source_tokens.is_empty() || target_tokens.is_empty() {
                return 0.0;
            }
            let a: HashSet<&str> = source_tokens.iter().copied().collect();
            let b: HashSet<&str> = target_tokens.iter().copied().collect();
            let intersection = a.intersection(&b).count();
            let union = a.union(&b).count();
            if union == 0 { 1.0 } else { intersection as f64 / union as f64 }
        }
    }
    ```

    **Heuristic helper functions (private):**

    - `fn is_past_participle(word: &str) -> bool`:
      Check against irregular past participle list (made, done, gone, said, told, shown, known, given, taken, seen, found, thought, brought, bought, caught, taught, felt, left, held, kept, meant, met, paid, put, run, read, sent, set, sat, spent, stood, lost, cut, built, led, understood, written, broken, chosen, driven, eaten, fallen, forgotten, frozen, hidden, ridden, spoken, stolen, sworn, thrown, worn).
      Also check regular patterns: ends with -ed, -en, -wn, -ne.

    - `fn passive_voice_ratio(tokens: &[&str]) -> f64`:
      Walk tokens pairwise: if token[i].to_lowercase() is a to-be form (am, is, are, was, were, be, been, being) and token[i+1] passes is_past_participle, count as passive construction. Return passive_count / (tokens.len() - 1).max(1). If tokens.len() < 2, return 0.0.

    - `fn classify_voice(tokens: &[&str]) -> Voice`:
      ratio > 0.3 -> Passive, ratio < 0.1 -> Active, else Unknown.

    - `fn hedging_assertive_score(tokens: &[&str]) -> f64`:
      Hedging words: might, could, perhaps, possibly, somewhat, apparently, seemingly, arguably, presumably, likely, maybe, probably, suggest, suggests, may, seem, seems, sometimes.
      Assertive words: must, will, always, never, clearly, obviously, definitely, certainly, undoubtedly, absolutely, every, none, shall, undeniable, unquestionably.
      Score = (hedging_count - assertive_count) / total_words.

    - `fn avg_sentence_length_words(text: &str) -> f64`:
      Split on sentence-ending punctuation (., !, ?). Count words per sentence. Average.

    - `fn avg_word_length_chars(tokens: &[&str]) -> f64`:
      Average char count per token.
