    - `pub fn register(&mut self, analyzer: Box<dyn AnalyzerPlugin>) -> Result<(), AnalysisError>`:
      1. Get `id` from `analyzer.id().to_string()`
      2. If `self.analyzers.contains_key(&id)` -> return `Err(AnalysisError::AlreadyRegistered(id))`
      3. Get dependencies from `analyzer.dependencies()`
      4. Check all Required dependencies exist:
         ```rust
         for dep in &dependencies {
             if let AnalyzerDependency::Required(dep_id) = dep {
                 if !self.analyzers.contains_key(dep_id) {
                     return Err(AnalysisError::DependencyNotFound(dep_id.clone()));
                 }
             }
         }
         ```
         (Optional dependencies that don't exist: silently accepted, no error.)
      5. Temporarily insert the analyzer: `self.analyzers.insert(id.clone(), analyzer);`
      6. Run cycle detection on the full graph:
         - Use DFS 3-color marking (White=0/Gray=1/Black=2)
         - For each unvisited node, run DFS following all dependencies (Required AND Optional, but only those present in registry)
         - If a Gray node is encountered -> cycle detected
         - Build a cycle path string for the error message
      7. If cycle detected: remove the just-inserted analyzer (`self.analyzers.remove(&id)`), return `Err(AnalysisError::CycleDetected(cycle_path_string))`
      8. If no cycle: return `Ok(())`

    - `pub fn unregister(&mut self, id: &str) -> Option<Box<dyn AnalyzerPlugin>>`: `self.analyzers.remove(id)`

    - `pub fn get(&self, id: &str) -> Option<&dyn AnalyzerPlugin>`: `self.analyzers.get(id).map(|b| b.as_ref())`

    - `pub fn contains(&self, id: &str) -> bool`: `self.analyzers.contains_key(id)`

    - `pub fn analyzer_ids(&self) -> Vec<&str>`: `self.analyzers.keys().map(|s| s.as_str()).collect()`

    - `pub fn len(&self) -> usize`: `self.analyzers.len()`

    **Cycle detection helper** (private function):
    ```rust
    fn has_cycle(analyzers: &HashMap<String, Box<dyn AnalyzerPlugin>>) -> Option<String> {
        #[derive(Clone, Copy, PartialEq)]
        enum Color { White, Gray, Black }

        let mut colors: HashMap<&str, Color> = analyzers.keys()
            .map(|k| (k.as_str(), Color::White)).collect();

        fn dfs<'a>(
            node: &'a str,
            analyzers: &'a HashMap<String, Box<dyn AnalyzerPlugin>>,
            colors: &mut HashMap<&'a str, Color>,
            path: &mut Vec<&'a str>,
        ) -> Option<String> {
            colors.insert(node, Color::Gray);
            path.push(node);

            if let Some(analyzer) = analyzers.get(node) {
                for dep in analyzer.dependencies() {
                    let dep_id = match &dep {
                        AnalyzerDependency::Required(id) => id.as_str(),
                        AnalyzerDependency::Optional(id) => id.as_str(),
                    };
                    // Only follow edges to nodes that exist in registry
                    if !analyzers.contains_key(dep_id) {
                        continue;
                    }
                    match colors.get(dep_id) {
                        Some(Color::Gray) => {
                            let cycle_start = path.iter()
                                .position(|&n| n == dep_id).unwrap();
                            let cycle: Vec<&str> = path[cycle_start..].to_vec();
                            return Some(format!("{} -> {}", cycle.join(" -> "), dep_id));
                        }
                        Some(Color::White) | None => {
                            if let Some(cycle) = dfs(dep_id, analyzers, colors, path) {
                                return Some(cycle);
                            }
                        }
                        Some(Color::Black) => {}
                    }
                }
            }

            path.pop();
            colors.insert(node, Color::Black);
            None
        }

        let ids: Vec<String> = analyzers.keys().cloned().collect();
        for id in &ids {
            if colors.get(id.as_str()) == Some(&Color::White) {
                let mut path = Vec::new();
                if let Some(cycle) = dfs(id.as_str(), analyzers, &mut colors, &mut path) {
                    return Some(cycle);
                }
            }
        }
        None
    }
    ```

    `pub struct ExecutionPlanner;` (stateless -- all methods are associated functions taking registry reference).

    `impl ExecutionPlanner`:

    - `pub fn plan(registry: &PluginRegistry) -> Result<Vec<String>, AnalysisError>`:
      Kahn's algorithm:
      1. Build adjacency list (forward edges: dependency -> dependent) and in-degree map from all registered analyzers:
         ```rust
         let ids = registry.analyzer_ids();
         let mut in_degree: HashMap<&str, usize> = ids.iter().map(|id| (*id, 0usize)).collect();
         let mut forward_edges: HashMap<&str, Vec<&str>> = ids.iter().map(|id| (*id, Vec::new())).collect();

         for &id in &ids {
             let analyzer = registry.get(id).unwrap();
             for dep in analyzer.dependencies() {
                 let dep_id = match &dep {
                     AnalyzerDependency::Required(s) => s.as_str(),
                     AnalyzerDependency::Optional(s) => s.as_str(),
                 };
                 // Only include edges for deps that exist in registry
                 if registry.contains(dep_id) {
                     // Edge: dep_id -> id (dep must run before id)
                     forward_edges.get_mut(dep_id).unwrap().push(id);
                     *in_degree.get_mut(id).unwrap() += 1;
                 }
             }
         }
         ```
      2. Initialize queue with all nodes having in-degree 0, sorted alphabetically for deterministic tie-breaking:
         ```rust
         let mut queue: VecDeque<&str> = {
             let mut zero_degree: Vec<&str> = in_degree.iter()
                 .filter(|(_, &deg)| deg == 0)
                 .map(|(&id, _)| id)
                 .collect();
             zero_degree.sort();
             zero_degree.into_iter().collect()
         };
         ```
      3. Process queue:
         ```rust
         let mut result: Vec<String> = Vec::with_capacity(ids.len());
         while let Some(node) = queue.pop_front() {
             result.push(node.to_string());
             let mut successors = forward_edges.get(node).cloned().unwrap_or_default();
             successors.sort(); // deterministic ordering
             for &succ in &successors {
                 let deg = in_degree.get_mut(succ).unwrap();
                 *deg -= 1;
                 if *deg == 0 {
                     // Insert maintaining sorted order in queue
                     let pos = queue.iter().position(|&q| q > succ).unwrap_or(queue.len());
                     queue.insert(pos, succ);
                 }
             }
         }
         ```
      4. Cycle check: if `result.len() < ids.len()` -> cycle exists:
         ```rust
         if result.len() < ids.len() {
             let mut stuck: Vec<&str> = in_degree.iter()
                 .filter(|(_, &deg)| deg > 0)
                 .map(|(&id, _)| id)
                 .collect();
             stuck.sort();
             return Err(AnalysisError::CycleDetected(
                 format!("cycle among: {}", stuck.join(", "))
             ));
         }
         ```
      5. Return `Ok(result)`

    - `pub fn plan_filtered(registry: &PluginRegistry, analyzer_ids: &[&str]) -> Result<Vec<String>, AnalysisError>`:
      1. Collect the transitive closure of Required dependencies for the requested analyzer_ids:
         ```rust
         let mut needed: HashSet<String> = HashSet::new();
         let mut stack: Vec<String> = analyzer_ids.iter().map(|s| s.to_string()).collect();
         while let Some(id) = stack.pop() {
             if needed.contains(&id) { continue; }
             if let Some(analyzer) = registry.get(&id) {
                 for dep in analyzer.dependencies() {
                     if let AnalyzerDependency::Required(dep_id) = dep {
                         if registry.contains(&dep_id) && !needed.contains(&dep_id) {
                             stack.push(dep_id);
                         }
                     }
                 }
             }
             needed.insert(id);
         }
         ```
      2. Run `plan(registry)` to get full topological order.
      3. Filter to only include IDs in `needed` set, preserving topological order:
         ```rust
         let full_order = Self::plan(registry)?;
         Ok(full_order.into_iter().filter(|id| needed.contains(id)).collect())
         ```
