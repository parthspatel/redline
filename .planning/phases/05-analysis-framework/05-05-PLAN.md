    ```rust
    use std::panic::{catch_unwind, AssertUnwindSafe};

    use super::{
        AnalyzerDependency, AnalysisError,
        AnalysisContext, AnalysisReport,

    };
    ```

    **Struct:**
    ```rust
    pub struct AnalysisCoordinator {
        registry: PluginRegistry,
    }
    ```

    **Implementation:**
    - `pub fn new(registry: PluginRegistry) -> Self`
    - `pub fn registry(&self) -> &PluginRegistry`
    - `pub fn run(&self, context: &AnalysisContext) -> Result<AnalysisReport, AnalysisError>`:
      Get topological order from `ExecutionPlanner::plan(&self.registry)?`, then execute in order.
    - `pub fn run_filtered(&self, context: &AnalysisContext, analyzer_ids: &[&str]) -> Result<AnalysisReport, AnalysisError>`:
      Get filtered order from `ExecutionPlanner::plan_filtered`, then execute.
    - `fn execute_in_order(&self, context: &AnalysisContext, order: &[String]) -> Result<AnalysisReport, AnalysisError>`:
      For each analyzer in order:
      1. Look up in registry (if not found -> Failed status, continue)
      2. Check if any Required dependency has failed -> Skipped status, continue
      3. Execute with `catch_unwind(AssertUnwindSafe(|| analyzer.analyze(context, &report)))`:
         - `Ok(Ok(value))` -> insert result, Success status
         - `Ok(Err(error))` -> Failed status with error message
         - `Err(panic)` -> extract panic message via downcast to &str/String, Failed status with "panic: {msg}"
      4. Record AnalyzerExecutionMeta with duration and order_index

    AssertUnwindSafe is safe because: context is immutable (&reference), report is only read (&report) by analyzers, mutations happen AFTER catch_unwind returns. (Pitfall #1)
    Extract panic message immediately, don't store raw payload. (Pitfall #5)
