    1. Replace the stub `crates/core/src/analysis/context.rs` with the full implementation:

       ```rust
       use crate::diff::edit_operation::{EditKind, EditOperation};
       use crate::diff::result::DiffResult;
       use crate::metrics::{MetricInput, MetricValue, MetricsEngine};
       ```

       `pub struct AnalysisContext<'a>` with fields:
       - `pub diff: &'a DiffResult`
       - `pub metrics_engine: &'a MetricsEngine`

       `impl<'a> AnalysisContext<'a>`:
       - `pub fn new(diff: &'a DiffResult, metrics_engine: &'a MetricsEngine) -> Self`

       - `pub fn change_operations(&self) -> Vec<(usize, &EditOperation)>`:
         Returns `(index, op)` pairs for all non-Equal operations from `self.diff.operations`. The index is the position in the ORIGINAL operations vector (critical for annotation correctness -- pitfall #3).
         ```rust
         self.diff.operations.iter().enumerate()
             .filter(|(_, op)| op.kind != EditKind::Equal)
             .collect()
         ```

       - `pub fn source_text_for_op(&self, op: &EditOperation) -> &str`:
         Extract source text slice. Uses `op.source_start..op.source_end` as TOKEN indices into `self.diff.source.tokens`, then maps to byte offsets via token spans. If `source_start == source_end`, return `""`.
         ```rust
         let tokens = &self.diff.source.tokens;
         let start = op.source_start as usize;
         let end = op.source_end as usize;
         if start >= end || start >= tokens.len() {
             return "";
         }
         let end = end.min(tokens.len());
         let byte_start = tokens[start].span.start() as usize;
         let byte_end = (tokens[end - 1].span.end() as usize).min(self.diff.source.normalized.len());
         &self.diff.source.normalized[byte_start..byte_end]
         ```

       - `pub fn target_text_for_op(&self, op: &EditOperation) -> &str`:
         Same pattern but uses `self.diff.target`, `op.target_start`, `op.target_end`.

       - `pub fn source_tokens_for_op(&self, op: &EditOperation) -> Vec<&str>`:
         Returns individual token text slices from source for this op's token range.
         ```rust
         let tokens = &self.diff.source.tokens;
         let start = op.source_start as usize;
         let end = (op.source_end as usize).min(tokens.len());
         if start >= end {
             return Vec::new();
         }
         (start..end).map(|i| {
             let s = tokens[i].span.start() as usize;
             let e = (tokens[i].span.end() as usize).min(self.diff.source.normalized.len());
             &self.diff.source.normalized[s..e]
         }).collect()
         ```

       - `pub fn target_tokens_for_op(&self, op: &EditOperation) -> Vec<&str>`:
         Same for target.

       - `pub fn compute_metric(&self, id: &str, input: &MetricInput<'_>) -> MetricValue`:
         Delegates to `self.metrics_engine.get(id, input)`.
