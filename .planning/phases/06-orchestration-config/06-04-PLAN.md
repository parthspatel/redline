**Struct definition:**
```rust
pub struct Redline {
    processor: TextProcessor,
    diff_computer: DiffComputer,
    metric_registry: MetricRegistry,
    analyzer_registry: PluginRegistry,
    cache: Option<CacheManager>,
    config_fingerprint: u64,
    config: RedlineConfig,
}
```

**Key design decisions:**
- `MetricRegistry` and `PluginRegistry` are owned by `Redline` — they are NOT Clone. Each `diff()` call creates a fresh `MetricsEngine` and `AnalysisCoordinator` that borrow from these registries. BUT: `MetricsEngine::new()` takes `MetricRegistry` by value (ownership), and `AnalysisCoordinator::new()` takes `PluginRegistry` by value. This is a problem — we can't move them out each call.

- **Solution:** Since MetricsEngine uses RefCell (not Sync), we CANNOT store a MetricsEngine in the struct. Instead, create fresh registries per call. But registries contain `Box<dyn Metric>` / `Box<dyn AnalyzerPlugin>` which are not Clone.

- **Actual solution from research:** The registries hold `Box<dyn Trait>` which are not Clone. We need to reconstruct fresh registries per `diff()` call. This is cheap — `register_builtins()` just allocates 37 small metric structs, and `register_builtin_analyzers()` allocates 4 analyzer structs. Store the config, not the registries.

    pub fn new(config: RedlineConfig) -> Result<Self, OrchestrateError> {
        // Build TextProcessor from config
        // The config owns the normalizers and tokenizer, but TextProcessor::new
        // takes Vec<Box<dyn Normalizer>> and Box<dyn Tokenizer> by value.
        // So we need to move them out of config.
        //
        // Solution: RedlineConfig should provide take_normalizers() and take_tokenizer()
        // methods, or the constructor takes them from the builder directly.
        //
        // Better: Have ConfigBuilder::build() return a tuple of (RedlineConfig, TextProcessor, DiffComputer)
        // or have Redline::new() consume the config and extract the parts it needs.

        let processor = TextProcessor::new(
            config.take_normalizers(),  // moves normalizers out
            config.take_tokenizer(),    // moves tokenizer out
            config.execution_mode,
        ).map_err(|e| OrchestrateError::Process(e))?;

        let diff_computer = DiffComputer::with_algorithm(config.take_algorithm());

        let fingerprint = config_fingerprint(&config);

        let cache = if config.cache_enabled {
            let cm = if let Some(mem_limit) = config.cache_memory_limit {
                CacheManager::with_memory_limit(config.cache_capacity, mem_limit)
            } else {
                CacheManager::new(config.cache_capacity)
            };
            Some(cm)
        } else {
            None
        };

        Ok(Self {
            config,
            processor,
            diff_computer,
            cache,
            config_fingerprint: fingerprint,
        })
    }
}

**diff() method:**
```rust
impl Redline {
    pub fn diff(&self, source: &str, target: &str) -> Result<RedlineResult, OrchestrateError> {
        // 1. Check cache
        let cache_key = PipelineCacheKey::new(source, target, self.config_fingerprint);
        if let Some(ref cache) = self.cache {
            if let Some(cached) = cache.get(&cache_key) {
                return Ok(RedlineResult {
                    diff: cached.diff,
                    metrics: cached.metrics,
                    analysis: cached.analysis.map(|arc| {
                        // We need to return AnalysisReport, but we have Arc<AnalysisReport>
                        // Since AnalysisReport is !Clone, we can't unwrap Arc unless refcount=1
                        // Store Arc in RedlineResult instead
                        arc
                    }),
                });
            }
        }

        // 2. Process texts
        let source_processed = Arc::new(
            self.processor.process(source)
                .map_err(OrchestrateError::Process)?
        );
        let target_processed = Arc::new(
            self.processor.process(target)
                .map_err(OrchestrateError::Process)?
        );

        // 3. Compute diff
        let diff_result = self.diff_computer.compute(
            source_processed.clone(),
            target_processed.clone(),
            None,
        ).map_err(OrchestrateError::Diff)?;

        // 4. Compute metrics (if enabled)
        let metrics = if self.metrics_enabled {
            let mut registry = MetricRegistry::new();
            register_builtins(&mut registry)
                .map_err(OrchestrateError::Metrics)?;
            let engine = MetricsEngine::with_default_cache(registry);

            // Determine which metrics to compute based on preset
            let metric_ids: Vec<&str> = engine.registry().ids().collect();
            let input = MetricInput::Pairwise(&source_processed, &target_processed);
            engine.get_many(&metric_ids, &input)
        } else {
            HashMap::new()
        };

        // 5. Run analysis (if enabled)
        let analysis = if self.analysis_enabled {
            let mut analyzer_registry = PluginRegistry::new();
            register_builtin_analyzers(&mut analyzer_registry)
                .map_err(OrchestrateError::Analysis)?;

            // Create a MetricsEngine for the AnalysisContext
            let mut metrics_registry = MetricRegistry::new();
            register_builtins(&mut metrics_registry)
                .map_err(OrchestrateError::Metrics)?;
            let metrics_engine = MetricsEngine::with_default_cache(metrics_registry);

            let analysis_context = AnalysisContext::new(&diff_result, &metrics_engine);
            let coordinator = AnalysisCoordinator::new(analyzer_registry);
            let report = coordinator.run(&analysis_context)
                .map_err(OrchestrateError::Analysis)?;
            Some(report)
        } else {
            None
        };

        // 6. Build result
        let result = RedlineResult {
            diff: diff_result.clone(),
            metrics: metrics.clone(),
            analysis: analysis.map(Arc::new),
        };

        // 7. Cache result
        if let Some(ref cache) = self.cache {
            let estimated = CachedResult::estimate_memory(&diff_result, &metrics, result.analysis.is_some());
            let cached = CachedResult {
                diff: diff_result,
                metrics,
                analysis: result.analysis.clone(),
                estimated_bytes: estimated,
            };
            cache.insert(cache_key, cached);
        }

        Ok(result)
    }
}
```

**RedlineResult::filter() method** (in result.rs):
```rust
impl RedlineResult {
    /// Filter operations using a predicate combinator.
    /// Returns an iterator over matching EditOperations.
    pub fn filter<'a>(&'a self, predicate: &'a Filter) -> impl Iterator<Item = &'a EditOperation> + 'a {
        let context = FilterContext {
            diff_result: &self.diff,
            analysis_report: self.analysis.as_deref(),
        };
        self.diff.operations.iter().filter(move |op| {
            predicate.matches(op, &context)
        })
    }
}
```

1. When building the MetricsEngine for analysis, create a SEPARATE one from the metrics computation — the analysis MetricsEngine is used by analyzers on-demand and has its own cache.
