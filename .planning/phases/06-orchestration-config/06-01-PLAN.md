**Preset expansion logic in `build()`:**

Phase 1: Expand preset defaults:
- **Fast:** empty normalizers vec, `WordTokenizer`, `Myers::new()`, metrics_enabled=true, analysis_enabled=false, cache_enabled=true, cache_capacity=64, execution_mode=Minimal

Phase 2: Overlay any `Some(value)` from builder fields onto defaults. **Overrides ALWAYS win.**

Phase 3: Validate:
- If cache_enabled and cache_capacity == 0 -> error
- If cache_memory_limit is Some(limit) and limit == 0 -> error
