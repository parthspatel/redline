2. Create the `Filter` enum — an enum-based predicate tree:
```rust
use crate::diff::EditKind;
use crate::analysis::IntentCategory;

#[derive(Debug, Clone)]
pub enum Filter {
    // Leaf predicates
    Kind(EditKind),
    MinLength(u32),
    MaxLength(u32),
    SourceContains(String),
    TargetContains(String),
    SpanRange { start: u32, end: u32 },
    MinTokenCount(u32),
    MaxTokenCount(u32),
    Intent(IntentCategory),

    // Combinators
    And(Box<Filter>, Box<Filter>),
    Or(Box<Filter>, Box<Filter>),
    Not(Box<Filter>),
}
```

4. Implement `matches()` method:
```rust
impl Filter {
    pub fn matches(&self, op: &EditOperation, ctx: &FilterContext<'_>) -> bool {
        match self {
            Filter::Kind(k) => op.kind == *k,
            Filter::MinLength(n) => op.source_len().max(op.target_len()) >= *n,
            Filter::MaxLength(n) => op.source_len().max(op.target_len()) <= *n,
            Filter::SourceContains(text) => {
                // Look up source text via diff_result
                self.source_text_contains(op, ctx, text)
            }
            Filter::TargetContains(text) => {
                self.target_text_contains(op, ctx, text)
            }
            Filter::SpanRange { start, end } => {
                // Check if op's source range overlaps [start, end)
                op.source_start < *end && op.source_end > *start
            }
            Filter::MinTokenCount(n) => {
                op.source_len().max(op.target_len()) >= *n
            }
            Filter::MaxTokenCount(n) => {
                op.source_len().max(op.target_len()) <= *n
            }
            Filter::Intent(category) => {
                self.matches_intent(op, ctx, category)
            }
            Filter::And(l, r) => l.matches(op, ctx) && r.matches(op, ctx),
            Filter::Or(l, r) => l.matches(op, ctx) || r.matches(op, ctx),
            Filter::Not(f) => !f.matches(op, ctx),
        }
    }
}
```

5. Implement helper methods for text matching:
- `source_text_contains()` — extract source text for the operation using DiffResult's source ProcessedText. Use the operation's source_start/source_end as token indices, get the tokens, extract the normalized text slice between the first token's span.start and last token's span.end. Check if it contains the target string.
- `target_text_contains()` — same for target side.
- `matches_intent()` — if analysis_report is Some, downcast the "edit_classifier" result to `EditClassifierResult`, find the `OperationClassification` matching this operation's index, and check if its `category` matches. Use the pattern from AnalysisReport::builtin::<EditClassifierResult>("edit_classifier"). If no analysis report or no matching classification, return false.

**Important:** For `source_text_contains` and `target_text_contains`, get the operation index by finding it in ctx.diff_result.operations (by pointer equality or by searching for matching source_start/source_end/target_start/target_end). Alternatively, add an `op_index` parameter — but per research, the cleaner approach is to have the filter work with just the EditOperation fields. For text contains, use the token indices to look up text from the ProcessedText. The token range is `[op.source_start..op.source_end)` for source and `[op.target_start..op.target_end)` for target.

For `matches_intent`, we need the operation index to look up the classification. Since Filter::matches receives a single op without its index, and the intent filter needs to find the classification by matching the op's position: iterate over the EditClassifierResult's classifications and match by source_start/source_end/target_start/target_end equality.

6. Implement operator overloads:
```rust
impl std::ops::BitAnd for Filter {
    type Output = Filter;
    fn bitand(self, rhs: Filter) -> Filter {
        Filter::And(Box::new(self), Box::new(rhs))
    }
}

impl std::ops::BitOr for Filter {
    type Output = Filter;
    fn bitor(self, rhs: Filter) -> Filter {
        Filter::Or(Box::new(self), Box::new(rhs))
    }
}

impl std::ops::Not for Filter {
    type Output = Filter;
    fn not(self) -> Filter {
        Filter::Not(Box::new(self))
    }
}
```
